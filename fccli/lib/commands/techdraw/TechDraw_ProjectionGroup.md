The TechDraw ProjectionGroup tool creates a multiview projection of one or more 3D objects, using the traditional first- or third-angle projection. The isometric views of the 4 front corners can also be included. The TechDraw View tool can also create a Projection Group. It is advisable to use that tool instead.
